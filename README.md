# ربات رایگان قیمت طلا، دلار، نقره و نفت برای تلگرام

این پروژه هر ۳۰ دقیقه قیمت‌ها را جمع‌آوری و در کانال تلگرام منتشر می‌کند.

## منابع

- ایران: TGJU
  - دلار آزاد: `price_dollar_rl`
  - طلای ۱۸ عیار: `geram18`
  - نقره ۹۹۹: `silver_999`
- جهانی: Biquote بدون API Key
  - Gold: `XAUUSD`
  - Silver: `XAGUSD`
  - Brent: `UKOIL`

## نصب بدون سرور پولی

بهترین روش رایگان این نسخه استفاده از **GitHub Actions** است. یک Repository عمومی بسازید، فایل‌های این پروژه را داخل آن قرار دهید و دو Secret زیر را اضافه کنید:

`TELEGRAM_BOT_TOKEN`

توکن Bot را از `@BotFather` بگیرید.

`TELEGRAM_CHAT_ID`

اگر کانال username عمومی دارد، می‌توانید مقدار آن را مثل `@my_channel` بگذارید. در غیر این صورت Chat ID کانال را قرار دهید.

## تنظیم کانال

1. در Telegram با `@BotFather` یک Bot بسازید.
2. Bot را به کانال اضافه کنید.
3. Bot را **Administrator** کنید و اجازه ارسال پیام بدهید.
4. Repository را در GitHub بسازید.
5. فایل‌های این پروژه را Upload کنید.
6. از مسیر Settings → Secrets and variables → Actions دو Secret بالا را بسازید.
7. از Actions → Publish market prices → Run workflow یک بار دستی اجرا کنید.
8. اگر پیام در کانال آمد، بعد از آن GitHub هر ۳۰ دقیقه workflow را اجرا می‌کند.

## تغییر فاصله انتشار

در فایل `.github/workflows/publish.yml` مقدار cron را تغییر دهید:

- هر ۳۰ دقیقه: `*/30 * * * *`
- هر ۱۵ دقیقه: `*/15 * * * *`
- هر ساعت: `0 * * * *`
- هر ۵ دقیقه: `*/5 * * * *`

برای کانال عمومی قیمت، پیشنهاد اولیه **۳۰ دقیقه** است.

## نکته مهم

TGJU وب‌سرویس رسمی پولی دارد؛ این پروژه از صفحات عمومی TGJU داده را می‌خواند و بنابراین به API پولی TGJU نیاز ندارد. TGJU در صفحات عمومی فعلی دلار آزاد، طلای ۱۸ عیار و نقره ۹۹۹ را نمایش می‌دهد.

Biquote نیز API عمومی بدون API Key برای XAUUSD، XAGUSD و UKOIL دارد.

این پروژه داده را برای انتشار عمومی بازنشر می‌کند؛ قبل از استفاده تجاری، شرایط استفاده و مجوزهای منابع را بررسی کنید.
